# Security Policy

## Supported versions

Security fixes target latest `main` and latest published npm version.

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities or include API keys, tokens, or private endpoint details in a report.

Use GitHub's private vulnerability reporting for this repository when available:

https://github.com/jamesjfoong/pi-ollama/security/advisories/new

If private reporting is unavailable, contact the maintainer through the GitHub profile:

https://github.com/jamesjfoong

Include:

- affected version or commit
- reproduction steps
- impact
- suggested mitigation, if known

Remove secrets from logs and examples before sending them.
